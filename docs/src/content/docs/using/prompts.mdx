Write a task once on the **Prompts** page and every connected MCP client lists it as a prompt.

<Screenshot name="prompts" alt="The Prompts page: saved prompts with their placeholders" />

- **Placeholders**: `{{customer}}` in the text becomes an argument the client asks for.
- **Shared or yours**: share a prompt with the workspace, or keep it to yourself.
- **Same rules**: every call a prompt leads to is checked and logged like any other.
